## 20:02 - 架构方案：接入沙箱与远端运行能力

- 只读分析 Agent Runtime、DSH 本地沙箱、审批、JobManager、Channel headless、ApiGateway 与 resume token 链路。
- 核心决策：采用“桌面端控制面客户端 + 独立远端执行控制面 + 沙箱 Worker”架构；在现有 Runtime Driver 上新增 Remote Runtime，保留本地运行回退；不采用 Electron 直连 SSH/Docker。
- 安全原则：审批策略与沙箱权限解耦；远端默认最小权限和 fail-closed；使用 Worker 租约、持久事件序列、短期任务令牌、取消 ACK 与沙箱销毁证明。
- 产出：`outputs/cherry-studio-remote-sandbox-upgrade-plan.html`，包含现状证据、目标架构、领域模型、接口契约、STRIDE 风险、Wave 0-4 路线及验收门禁。
- 验证：HTML 结构检查通过，20,978 bytes，13 个章节；未修改业务源码。
