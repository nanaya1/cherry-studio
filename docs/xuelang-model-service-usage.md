# 雪浪工匠登录授权、Token 统计与模型配置使用说明

> 适用产品：MEA Cowork / Cherry Studio 企业版
>
> 本说明依据当前系统实现编写。不同构建版本的菜单位置或文案可能略有差异，请以实际界面为准。

## 1. 使用目标

本文说明如何完成以下操作：

- 登录并授权雪浪工匠模型服务；
- 启用、同步或添加雪浪工匠模型；
- 发起测试请求，验证模型调用；
- 在“用量统计”中查看请求量、Token 消耗和成本；
- 处理常见的授权、会话和统计异常。

完成操作后，应满足以下条件：

- 雪浪工匠账号已授权，供应商处于启用状态；
- 所需模型已启用；
- 模型可以正常返回结果；
- “用量统计”中能看到对应的请求和 Token 数据。

## 2. 操作流程

1. 进入 **设置 → 模型服务**。
2. 在供应商列表中选择 **雪浪工匠**。
3. 点击 **雪浪工匠授权登录**，在浏览器中完成登录和授权。
4. 返回客户端，确认账号信息、余额和登录状态。
5. 在同一页面下方启用或添加所需模型。
6. 使用雪浪工匠模型发起一次测试请求。
7. 进入 **设置 → 用量统计**，查看 Token、请求量和成本。

## 3. 前置条件

操作前请确认：

- 客户端已正常安装并可以访问互联网；
- 已拥有可登录的雪浪工匠账号；
- 默认浏览器可以打开雪浪工匠授权页面；
- 操作系统允许浏览器通过 `meacowork://oauth/callback` 返回客户端；
- 企业网络、防火墙或代理未阻断雪浪工匠服务；
- 账号具备可用额度和相应模型使用权限。

> **安全提示**
>
> 登录授权采用浏览器授权和回调机制。正常流程不要求在客户端手工粘贴账号密码，也不建议通过聊天、邮件或截图传递令牌和密钥。

## 4. 登录并授权雪浪工匠

### 4.1 进入供应商页面

1. 打开客户端。
2. 进入 **设置**。
3. 点击 **模型服务**。
4. 在左侧供应商列表中选择 **雪浪工匠**。

页面上方是登录授权区域，页面下方是模型列表。

### 4.2 发起授权登录

1. 在登录授权区域确认当前状态为 **未登录**。
2. 点击 **雪浪工匠授权登录**。
3. 系统自动打开默认浏览器并进入雪浪工匠授权页面。
4. 在浏览器中登录雪浪工匠账号。
5. 阅读授权范围后确认授权。
6. 授权完成后，浏览器通过客户端回调返回应用。

授权过程通常包含读取账户余额、读取用量和管理访问令牌所需权限。请勿关闭客户端，否则回调可能无法完成。

### 4.3 确认授权结果

授权成功后，客户端应出现以下状态：

- 登录区域显示账号昵称或邮箱；
- 显示雪浪工匠标识及账号分组信息；
- “余额”位置显示美元金额；余额暂未拉取成功时可能显示 `-`；
- 按钮由 **雪浪工匠授权登录** 变为 **退出登录**；
- 雪浪工匠供应商自动启用；
- 系统已自动获取并保存用于模型调用的 OAuth 密钥。

**成功判定：** 页面显示账号信息和“退出登录”，且供应商已启用。

> 当前雪浪工匠授权卡片不提供“充值”按钮。充值或额度管理请通过雪浪工匠官方平台完成，客户端当前没有充值入口。

## 5. 配置雪浪工匠模型

模型配置位于雪浪工匠供应商详情页的登录授权区域下方，不是独立页面。

### 5.1 查看并启用模型

1. 保持在 **设置 → 模型服务 → 雪浪工匠** 页面。
2. 向下滚动至模型列表。
3. 使用搜索框查找目标模型。
4. 启用需要使用的模型，关闭不需要展示或使用的模型。
5. 如界面提供同步功能，可先同步供应商模型列表，再选择模型。

当前系统预置模型包括：

| 模型显示名称 | 模型标识 | 适用说明 |
| --- | --- | --- |
| Qwen3.8 27B | `qwen3-8-27b` | 通用对话、内容生成及综合任务 |
| 化工大模型 | `chemindustry` | 化工行业相关知识与专业任务 |

实际可用模型可能随服务端目录和产品版本变化，以客户端模型列表为准。

### 5.2 添加自定义模型

仅在模型已由雪浪工匠服务端开放、但未显示在列表中时执行：

1. 在模型列表中点击添加模型入口。
2. 按界面要求填写模型标识和显示名称。
3. 保存后启用该模型。
4. 发起测试请求，确认模型标识有效。

请准确填写服务端认可的模型标识。错误的模型标识通常会导致“模型不存在”“无权限”或请求失败。

### 5.3 验证模型调用

1. 返回对话或相应业务功能页面。
2. 在模型选择器中选择已启用的雪浪工匠模型。
3. 输入简短测试内容，例如：`请回复：连接测试成功`。
4. 发送请求并等待模型响应。

**成功判定：** 请求正常返回内容，且未出现鉴权失败、余额不足或模型不可用提示。

> 建议在查看 Token 统计前至少完成一次成功请求。没有产生请求记录时，“用量统计”会显示“暂无用量”。

## 6. 查看 Token 与用量统计

### 6.1 进入用量统计

1. 打开 **设置**。
2. 点击 **用量统计**。
3. 等待统计数据加载完成。

该页面汇总所有已启用供应商的用量，并非只统计雪浪工匠。需要单独分析雪浪工匠时，可按供应商分组或筛选。

### 6.2 关键指标

| 指标 | 说明 | 管理用途 |
| --- | --- | --- |
| 总成本 | 当前统计范围内模型调用产生的费用 | 费用核对与预算控制 |
| 总请求 | 成功写入统计记录的模型请求次数 | 评估调用频率 |
| 总 Token | 输入、输出及相关 Token 的汇总 | 衡量模型资源消耗 |
| 缓存命中率 | 可复用缓存命中的比例 | 评估成本和响应优化效果 |

页面还可能显示以下洞察：

- 活跃天数；
- 峰值日；
- 用量最高模型；
- 日均用量；
- 按时间粒度展示的趋势图；
- 按供应商、模型、来源或 API 密钥分组的分布图；
- 可排序、可分页的用量明细。

### 6.3 单独查看雪浪工匠用量

1. 在统计分析区域选择按 **供应商** 分组。
2. 在图表、分布或明细中定位 **雪浪工匠**。
3. 根据需要调整日期范围和时间粒度。
4. 记录总 Token、总请求和总成本。
5. 如需定位异常消耗，可进一步切换为按 **模型** 或 **API 密钥** 分组。

**成功判定：** 完成雪浪工匠模型请求后，统计页出现相应请求记录，且总请求和总 Token 不再为零。

### 6.4 数据解读注意事项

- 统计数据可能不是实时刷新，刚完成请求时可稍后刷新页面；
- 总 Token 与雪浪工匠官方账单口径可能存在时间范围、缓存计费或舍入差异；
- 切换日期范围后，应同时核对图表和明细的统计区间；
- 多供应商并用时，先按供应商分组，避免将其他服务的消耗计入雪浪工匠；
- 若请求失败且未形成有效用量记录，统计页可能不会增加请求数。

## 7. 退出登录与重新授权

### 7.1 退出登录

1. 进入 **设置 → 模型服务 → 雪浪工匠**。
2. 点击 **退出登录**。
3. 在确认窗口中确认退出。
4. 等待退出成功提示。

退出后，本地 OAuth 密钥会被移除，供应商登录状态失效。若提示“已在本地退出登录，但服务器端令牌撤销可能失败”，说明本地已退出，但建议登录雪浪工匠官方平台检查授权状态。

### 7.2 重新授权

出现以下情况时建议重新授权：

- 页面提示“会话已失效，请重新登录”；
- 模型请求持续返回鉴权失败；
- 账号权限或分组发生变化；
- OAuth 密钥已被服务端撤销；
- 需要更换雪浪工匠账号。

重新授权前可先退出当前账号，再点击 **雪浪工匠授权登录** 完成新一轮授权。

## 8. 常见问题与处理

| 问题现象 | 可能原因 | 处理方法 |
| --- | --- | --- |
| 点击授权后浏览器未打开 | 默认浏览器、系统安全策略或网络异常 | 检查默认浏览器和系统弹窗；重试授权；确认网络可访问雪浪工匠服务 |
| 浏览器授权成功但客户端无变化 | `meacowork://` 回调未返回客户端，或客户端被关闭 | 保持客户端运行；允许系统打开客户端；重新发起授权 |
| 提示“OAuth 权限不足” | 授权范围未完整授予 | 退出后重新授权，并确认同意所需权限 |
| 提示取消登录 | 用户取消、关闭授权页或拒绝授权 | 重新点击“雪浪工匠授权登录”并完成全部步骤 |
| 授权长时间无响应 | 浏览器未完成回调或流程超时 | 关闭旧授权页，返回客户端重新发起；单次授权最长等待约 10 分钟 |
| 页面显示“会话已失效，请重新登录” | 本地存在 OAuth 密钥，但登录令牌已失效 | 按页面提示重新登录或重新获取密钥 |
| 余额显示 `-` | 余额接口暂时不可用或网络异常 | 稍后刷新；确认账号和网络；不影响时可先测试模型调用 |
| 模型列表没有目标模型 | 未同步、服务端未开放或模型标识不在目录中 | 先同步列表；确认账号权限；必要时添加正确的自定义模型标识 |
| 模型请求提示无权限 | 账号分组、模型权限或授权范围不足 | 检查雪浪工匠账号权限；重新授权；联系服务管理员 |
| 模型请求提示余额不足 | 账号额度不足 | 前往雪浪工匠官方平台处理额度；客户端当前无充值入口 |
| 用量统计显示“暂无用量” | 尚未成功调用模型，或统计尚未刷新 | 先完成一次成功请求；稍后刷新；检查日期范围 |
| 统计中看不到雪浪工匠 | 当前按其他维度聚合，或请求未形成记录 | 切换为按供应商分组；确认请求成功；检查统计时间范围 |
| 退出时出现令牌撤销警告 | 服务端撤销令牌失败，但本地已退出 | 到雪浪工匠官方平台核查授权并手工撤销（如平台支持） |

## 9. 管理员验收清单

完成配置后，逐项确认：

- [ ] 能进入“设置 → 模型服务 → 雪浪工匠”；
- [ ] 点击“雪浪工匠授权登录”可打开浏览器授权页；
- [ ] 授权后客户端显示账号昵称或邮箱；
- [ ] 页面显示余额或可识别的余额占位状态；
- [ ] 页面显示“退出登录”；
- [ ] 雪浪工匠供应商处于启用状态；
- [ ] 所需模型已在模型列表中启用；
- [ ] 已使用目标模型完成一次成功请求；
- [ ] “设置 → 用量统计”中总请求和总 Token 已产生数据；
- [ ] 可按供应商定位雪浪工匠用量；
- [ ] 管理员已了解客户端当前不提供雪浪工匠充值入口。

## 10. 权限与安全建议

- 使用组织分配的雪浪工匠账号，避免多人共享个人账号；
- 不在文档、聊天记录或工单中明文记录令牌和密钥；
- 人员离岗或职责变更时，及时退出客户端并在服务端撤销授权；
- 定期核对用量统计与官方账单，关注异常峰值和高消耗模型；
- 对自定义模型标识执行变更登记，避免误配模型；
- 出现持续鉴权失败时，应优先重新授权，不要反复新增未知来源的密钥。
