A · 统一工作台（推荐）

固定主侧栏 + 单一右侧内容区。资源中心、定时任务、普通对话与 Agent 会话都作为同级工作区切换。

优点：最贴近参考图，入口稳定，用户心智最简单。

代价：需要调整 AppShell 与设置页在主工作区中的承载方式。

B · 三级导航工作台

主侧栏选择功能，右侧根据页面再出现局部二级栏，沿用现有设置页和 MCP 的 split layout。

优点：对复杂资源管理最友好，现有页面改造较小。

代价：部分页面形成三栏，窄窗口拥挤，也不如参考图简洁。

C · 轻壳 + 页面自治

侧栏只负责顶层入口，各右侧页面最大程度保留自己的 Header、Tab 和局部布局。

优点：开发边界清楚，对现有功能侵入最小。

代价：不同页面的布局语言可能不够统一，需额外视觉收口。
