两种模式的差异

普通对话
  • 选择 Assistant 与模型
  • 支持文件、图片、知识库、联网搜索
  • 首次发送时调用现有 reuseOrCreateTopic
  • 创建后进入现有 HomePage 消息视图
智能体任务
  • 选择 Agent 与 Workspace
  • 可使用 Agent 已绑定的技能、MCP 和 Channels
  • 首次发送时调用现有 reuseOrCreateSession
  • 创建后进入现有 AgentPage 工作区

关键交互约束

  • 切换“普通对话 / 智能体任务”只改变输入区配置，不提前生成历史记录。
  • 推荐卡只填入任务意图或切换合适模式，不自动发送，避免误创建会话。
  • 普通对话保持 Assistant 语义；智能体任务保持 Agent + Workspace 语义，不合并底层数据模型。
  • 发送成功后，顶部标题、左侧选中项和 URL 同步为实际 Topic 或 Session。
  • 创建失败时保留输入内容，在输入区就地展示错误并允许重试。
