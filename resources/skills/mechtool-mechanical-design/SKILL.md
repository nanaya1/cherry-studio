## 何时使用

用户提出以下类型问题时启用本 skill：
- **数据查询**: "45钢的许用应力?" "深沟球轴承6205尺寸?" "M12螺栓预紧力?" "O型圈规格?"
- **选型指导**: "这个工况选什么轴承/弹簧/密封?"
- **规范查询**: "公差等级IT7对应多少?" "表面粗糙度怎么标?"
- **公式计算**: "轴的强度校核公式?" "弹簧刚度计算?"
- **设计禁忌**: "齿轮结构设计有哪些禁忌?"

## 查询流程

1. **确定主题域** → 从下方索引选择对应 reference 文档
2. **读取参考文档** → 找到相关内容后回答
3. **细节不足时** → 检索 skill 内嵌全量语料(645万字, 自包含无需联网):
   ```bash
   python3 scripts/search_corpus.py topics                         # 13 个主题组
   python3 scripts/search_corpus.py search "深沟球轴承"             # 标题+全文搜索
   python3 scripts/search_corpus.py read <URL路径或标题>            # 读整篇正文
   python3 scripts/search_corpus.py grep "许用应力" --topic 轴承与轴  # 正文逐行匹配
   ```
4. **涉及计算** → 给出公式+符号单位+代入示例

## 回答风格

- 数据查询: 直接给出数值表或关键数据 + 标准号出处

- 计算问题: 公式 → 符号含义 → 代入计算
