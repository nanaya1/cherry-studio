#### 特定表示法
特定表示法
说明
沿结合面剖切或拆卸画法
在装配图中，可假想沿某些零件的结合面剖切此时，在零件结合面上不画剖面线
假想画法
为了表示运动零件的极限位置或部件和相邻零件（或部件）的相互关系，可以用双点划线画出其轮廓
夸大画法
对薄片零件，细丝弹簧、微小间隙等，若按它们的实际尺寸在装配图中很难画出或难以明显表示时，均可不桉比例而采用夸大画法
规定画法和简化画法
在装配图中，零件的工艺结构，如圆角、倒角、退刀槽等可不画出。对于若干相同的零件组，如螺栓连接等，可详细地画出一组或几组，其余只需用点划线表示其装配位置
#### 装配图上的尺寸
尺寸种类
定义
规格尺寸
表达产品或部件的性能和规格的尺寸
装配尺寸
说明产品或部件内零件之间装配要求的尺寸包括配合尺寸和重要的相对位置尺寸
外形尺寸
表示产品或部件的总长、总宽和总高的尺寸
安装尺寸
表示产品或部件安装在基础上或其他零、部件上所必需的尺寸
其他重要尺寸
设计时的计算尺寸(包括装配尺寸链)、装配时的加工尺寸、运动件的极限位置尺寸以及某些重要的结构尺寸等
#### 零部件序号的编排
注：（1）装配图中所有的零、部件都必须编号。
（2）装配图中一个部件可只编写一个序号同一装配图中相同的零、部件应编写同样的序号。
（3）装配图中零、部件的序号，应与明细栏中的序号一致。
| 项目 | 规定 | 图例
| 指引线及序号 | 在指引线的水平线（细实线）上或圆（细实线）内注写序号，序号字高比该装配图中所注尺寸数字高度大一号 | ![图](https://www.mechdoc.cn/images/drawingandaccuracy/drawingandaccuracy_assemblydrawing1.png)
|   | 在指引线的水平线（细实线）上或圆（细实线）内注写序号，序号字高比该装配图中所注尺寸数字高度大两号 | ![图](https://www.mechdoc.cn/images/drawingandaccuracy/drawingandaccuracy_assemblydrawing1.png)
|   | 在指引线附近注写序号，序号字高比该装配图中所注尺寸数字高度大两号 |
| 序号书写方向 | 装配图中的序号应按水平或铅垂方向排列整齐 |
| 序号一致 | 同一装配图中编注序号的形式应一致 |
| 序号不重复 | 相同的零、部件用一个序号，一般只标注一次对多处出现的，必要时也可重复标注 |
| 指引线的起迄 | 指引线应自所指部分的可见轮廓内引出，并在末端画一圆点，若所指部分（很薄的零件或涂黑的剖面）内不便画圆点时，可在指引线的末端画出箭头，并指向该部分的轮廓
| ![图](https://www.mechdoc.cn/images/drawingandaccuracy/drawingandaccuracy_assemblydrawing3.png)
|   | 指引线相互不能相交当通过有剖面线的区域时，指引线不应与剖面线平行
|   | 一组紧固件以及装配关系清楚的零件组，可以采用公共指引线 | ![图](https://www.mechdoc.cn/images/drawingandaccuracy/drawingandaccuracy_assemblydrawing4.png)
| 序号的编排顺序 | 按顺时针或逆时针方向顺次排列在整个图上无法连续时，可只在每个水平或铅垂方向顺次排列
|   | 也可按装配图明细栏中的序号排列，采用此种方法时，应尽量在每个水平或铅垂方向顺次排列
