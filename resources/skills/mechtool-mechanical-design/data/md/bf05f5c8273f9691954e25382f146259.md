## 介绍
该软件可以帮助用户生成并预览产品尺寸图，1:1真图，和3D模型
该软件可以帮助用户打印减速电机或减速箱图纸，用户也可以将生成的图纸直接拖入自己的CAD系统。该软件采用易于操作的windows界面。
语言:
英语, 德语, 法语, 丹麦语, 芬兰语, 荷兰语, 意大利语, 波兰语, 葡萄牙语, 瑞典语, 西班牙语, 捷克语, 汉语, 美式英语
系统要求：
Windows XP, Windows Vista, Windows 7, Windows 8, Windows 10
发布:
9.2.4
使用：
解压后直接双击NordCAD.exe运行。
## NORD CAD 9.2.4
NORD CAD 9.2.4已无法使用。离线版已取消，请使用网页版。
