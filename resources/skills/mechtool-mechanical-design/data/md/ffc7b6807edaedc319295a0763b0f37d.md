#### inventor 2016 安装要求
| Inventor 2016 Windows 系统要求
| 操作系统
| 建议：
64 位 Microsoft® Windows® 7 Service Pack 1 或 Windows 8.1¹
或 Microsoft Windows 10（桌面操作系统）¹
最低要求：
64 位 Microsoft Windows 7 Service
Pack 1
| CPU 类型
| 建议：
Intel® Xeon® E3 或 Core i7 或同等级别内核，3.0 GHz 或更高²
最低要求：
64 位 Intel® 或 AMD，2 GHz 或更高²
| 内存
| 建议：
16 GB 或更大 RAM³
最低要求：
8 GB RAM（少于 500 个零部件³）
| 磁盘空间
| 建议：
250 GB 可用磁盘空间或更多³
最低要求：
100 GB 可用磁盘空间³
| 显卡
| 建议：
支持 Microsoft® Direct3D 11® 或更高版本的显卡⁴
最低要求：
支持 Microsoft® Direct3D 10® 或更高版本的显卡⁴
| 其他
-
- DVD-ROM⁵
-
- 1280 x 1024 或更高的屏幕分辨率
-
- Internet 连接，用于 Autodesk® 360 功能、Web 下载和 Subscription Aware 访问
-
- Adobe® Flash® Player 15⁶
-
- Microsoft® Internet Explorer® 8 或更高版本
-
- 在本地完整安装的 Microsoft® Excel 2007、2010 或 2013，用于 iFeature、iPart、iAssembly、螺纹相关命令、间隙/螺纹孔的创建、全局 BOM 表、明细栏、修订表、电子表格驱动的设计和位置表达的 Studio 动画。 Excel Starter®、Online Office 365® 和 OpenOffice® 不受支持。
-
- 需要使用 64 位 Microsoft Office 导出 Access 2007、dBase IV、文本和 CSV 格式。
-
- Microsoft .NET Framework 4.5⁷
| 对于复杂模型、复杂模具部件和大型部件（通常多于 1,000 个零件）
| 操作系统
| 建议：
64 位 Microsoft® Windows® 7 Service Pack 1、Microsoft Windows 8.1¹ 或 Microsoft Windows 10（桌面操作系统）。
| CPU 类型
| 建议：
Intel® Xeon® E3 或 Core i7 或同等级别内核，3.30 GHz 或更高²
| 内存
| 建议：
20 GB RAM 或更大³
| 硬盘
| 建议：
500 GB 可用磁盘空间或更多³
| 显卡
| 建议：
支持 Microsoft® Direct3D 11® 或更高版本的显卡⁴
| 其他
-
- DVD-ROM⁵
-
- 1280 x 1024 或更高的屏幕分辨率
-
- Internet 连接，用于 Autodesk® 360 功能、Web 下载和 Subscription Aware 访问
-
- Adobe® Flash® Player 15⁶
-
- Microsoft® Internet Explorer® 8 或更高版本
-
- 在本地完整安装的 Microsoft® Excel 2007、2010 或 2013，用于 iFeature、iPart、iAssembly、螺纹相关命令、间隙/螺纹孔的创建、全局 BOM 表、明细栏、修订表、电子表格驱动的设计和位置表达的 Studio 动画。 Excel Starter®、Online Office 365® 和 OpenOffice® 不受支持。
-
- 需要使用 64 位 Microsoft Office 导出 Access 2007、dBase IV、文本和 CSV 格式。
-
- Microsoft .NET Framework 4.5⁷
-
- Inventor 和 Vault 在指定的计算机上必须同时为同一语言。这些应用程序的英文版可以在所有语言的操作系统上运行。这些应用程序的其他语言版本将在具有相同语言的操作系统上运行。
-
- Inventor 2016 经过优化，能够利用 Pentium 4、AMD Athlon 64 和 AMD Opteron 处理器支持的 SSE2 扩展指令集。Inventor 2016 在不支持 SSE2 的计算机上无法安装。用户可以在 Internet 上找到一些报告 CPUID（包括支持的指令集）的实用程序。
-
- Autodesk 建议使用的设置为：允许 Microsoft Windows 根据需要管理虚拟内存。硬盘必须保留至少相当于系统内存 (RAM) 两倍的可用空间。
-
- 请参考 [Autodesk 已发布的显卡信息]()。
-
- 如果从 USB 或下载软件进行安装，则不需要使用 DVD-ROM 驱动器。
-
- Inventor 帮助系统的多媒体学习组件（例如用户界面视频导览、命令参考和演示动画）要求安装 Adobe Flash Player 10。如果尚未安装，可以[从 Adobe 网站下载]()。
-
- 由 Autodesk 产品安装程序提供。
