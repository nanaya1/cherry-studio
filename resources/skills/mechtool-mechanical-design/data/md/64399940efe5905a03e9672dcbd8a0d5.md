#### 软件介绍
MITCalc是一套工程、制造和技术计算，旨在使日常工程任务显著更快和更容易。 经过精心设计，所有计算都旨在通过设计机械零件的众多步骤来可靠，准确，快速地指导用户。
整个系统可以解决众多技术问题和工程计算，而无需专业知识。其中包括对许多具有直接2D和3D输出的 CAD系统的支持。
您是机械或设计工程师、机械设计师，还是大学生？ 您是否需要使用专业的计算机辅助系统，却不愿意为不必要的复杂或难以学习的解决方案支付数千美元？ 如果您的回答是肯定的，则可以从MITCalc所提供的服务中受益！
MITCalc为许多常见的工程任务提供了设计和验证计算, 包括: 正齿轮、 锥齿轮和准双曲面齿轮、 蜗轮、 行星齿轮、 同步带、 皮带传动, 滚子链、 轴承、 弹簧、 梁、 列屈曲、 板的挠度和应力、 旋转壳​​体的变形和应力、
轴、 传动螺杆和滚珠丝杠、 螺栓联结、 轴联结、 联轴器、 销、 公差、 公差分析、 焊接联结、 技术公式等。 如需了解完整的计算列表，请浏览产品页面。 MITCalc用户还可以浏览多组材料、比较表和决策表，
包括用于管理已完成任务的系统。 同时支持英制和公制单位。所有计算可根据 ANSI，ISO，DIN，BS，CSN，日本和其他标准进行处理。

重要提示：
为确保与各种 Microsoft Excel 版本完全兼容，提供了两种不同的软件包。
一种为旧版本的 MS Excel (2000/XP/2003/2007) 设计，另一种与 MS Excel 2007 及更高版本兼容。两个 MITCalc 安装包都支持 MS Excel 2007。
安装注意事项：
MITCalc 由自动翻译器翻译成另外 15 种语言（ES、FI、HU、IT、JP、KO、NL、NO、PL、PT、RU、SK、SL、SV、TR）。每个安装都包含所有翻译。
*) Microsoft Excel（版本 XP、2003、2007、2010、2013、2016、2019、2021、365），包括 VBA 支持（建议完全安装 Microsoft Office）。
*) MS Excel 中的安全设置必须设置为允许启动嵌入式 VBA 应用程序。
MS Excel XP,2003：Excel ->菜单工具->宏->安全->启用 VBA 宏
MS Excel 2007：Office按钮->Excel选项->信任中心->信任中心设置->宏设置->启用 VBA 宏
MS Excel 2010, 2013, 2016, 2019, 2021、365：菜单文件->Excel选项->信任中心->信任中心设置->宏设置->启用 VBA 宏
**)必须正确安装 SolidWorks / Autodesk Inventor / Solid Edge 才能正确运行 MITCalc 计算。
**)完成 MITCalc 安装后，宏将自动启动连接插件的附加安装到 SolidWorks、Autodesk Inventor 或 Solid Edge。如果系统提示您，请启用宏以运行。也可以从开始菜单 -> MITCalc -> SolidWorks / Inventor / Solid Edge 插件安装手动开始将连接安装到 CAD 系统中。
