## MSC_ADAMS_v2017.2_win64
#### 软件简介
MSC Adams 2017是一款由msc公司推出的专业多体动力学和运动分析软件，仅适用于64位操作系统，
MSC Adams 2017可以帮助工程师快速创建和测试机械系统的模型，并拥有操作简单，分析速度快的特点。新版本的adams还带来了全新的性能，
包括模拟齿轮噪音、高效的建模命令语言等功能，同时还改进了有限元部件性能。
ADAMS2017特色
1、软件界面友好，操作简单，易学易用
2、三维实体、弹性体碰撞和冲击分析，摩擦、间隙 分析
3、极好的解算稳定性，最早支持SMP并行计算
4、支持系统参数化实验设计、优化分析
5、独特的振动分析能力，能在频域中分析机构任意运动 状态的下系统振动性能
6、提供多学科软件接口，包括与CAD、FEA、CSD(控制仿真软件)之间的接口
7、提供凝聚了丰富行业应用经验、实际工程问题的专业化产品
更新说明
Adams 2017在使用功能上做了多方面的性能提升，同时推出了一些全新应用。MSC Adams v2017版的主要亮点包括Adams Machinery齿轮高级3D接触——模拟齿轮噪音，以改善NVH性能;Python脚本：建模——更高效的命令语言，实现更容易的建模自动化;有限元部件改进——增强了捕捉梁和绳索大变形的性能;FMI模型导入——在Adams中更容易验证控制器设计。
MSC Adams v2017机械齿轮通过齿轮副之间的顺应性，是作为刚性部件被建模的。Adams 2017中，MSC Adams团队引入了齿轮齿的灵活性功能。此功能允许用户定义齿轮零件几何形状和材料属性，从中创建有限元模型(FEM)并在后台求解以定义齿符合性。它包括一个友好的用户界面，其中不需要Nastran的知识，因为网格化和FEA是完全自动化的。
Python脚本帮助工程师自动化他们的模拟过程，如建模和后处理。是第一个提供Python脚本替代Adams View命令语言(cmd)的多版本计划。此版本代表第一个可以使用本地Python向Adams GUI发出命令的版本。第一阶段将涵盖Adams视图中的大多数建模操作。
FE有限元零部件本地的非线性分析技术，帮助用户捕获具有较大变形的组件，例如梁等。MSC Adams v2017中对此功能进行了增强，以提高性能和可用性的非线性梁元件。
Adams Controls支持与遵守功能样机接口(FMI)标准的工具进行交互的协同仿真风格。 通过这个新版本，Adams Controls还支持FMI模型交换模型导入风格的交互。 此功能现在可用于所有符合FMI模型交换标准的工具。

#### 安装步骤
1、下载完成MSC Adams 2017官方原版以及MAGNiTUDE破解文件，在下载好的文件夹“MAGNiTUDE”中找到并双击运行MSC_Calc_20170630.exe。
2、运行MSC_Calc_20170630.exe后输入“Y”然后按回车键（enter）在当前目录下生成许可文件
3、看到生成了许可文件。
4、回到数据包中找到并运行msc_licensing_11.9_windows3264.exe。
5、运行msc_licensing_11.9_windows3264.exe，点击next开始安装许可文件
6、看到HostID(主机标识):704D7B29CD15,点击next进入下一步
7、选择第一项“New installation（新的安装）”然后点击next
8、不要更改安装路径，直接点击next
9、点击browse找到我们开始时生成的许可文件license.dat，路径：多体动力学仿真软件 MSC ADAMS v2017msadam017MAGNiTUDElicense.dat，然后选择第二项“Select this box to start the License Server automatically(选择此框将自动启动许可证服务器)”在点击next
10、点击next进入下一步
11、许可成功点击“确定”：
12、点击“finish”结束
13、回到数据包中找到“adams_2017.2_windows64.exe”，
14、双击“adams_2017.2_windows64.exe”开始安装，如下图
![MSC Adams 2017](https://www.mechdoc.cn/images/CAE/CAE_adams1.jpg)
15、点击next出现协议，选择i accept也就是我同意
![MSC Adams 2017](https://www.mechdoc.cn/images/CAE/CAE_adams2.jpg)
16、设置一下用户信息和公司信息，也可以默认
![MSC Adams 2017](https://www.mechdoc.cn/images/CAE/CAE_adams3.jpg)
17、选择安装类型，选择full完整安装，安装目录默认为“C:MSC.SoftwareAdams2017_2”，点击browse可以更改
![MSC Adams 2017](https://www.mechdoc.cn/images/CAE/CAE_adams4.jpg)
18、如下图，继续next即可开始安装
![MSC Adams 2017](https://www.mechdoc.cn/images/CAE/CAE_adams5.jpg)
19、开始正式的安装，因电脑配置不同安装所需时间也不同，请耐心等待
20、安装完成后会弹出以下界面，点击“browse”选择前面生成的许可文件license.dat（许可安装中新生成的），路径C:MSC.SoftwareMSC.Licensing11.9license.dat,
![MSC Adams 2017](https://www.mechdoc.cn/images/CAE/CAE_adams6.jpg)
21、点击next,选择第一项，第一项为在电脑桌面生成快捷方式，然后点击next
22、这里不用进行任何选择，直接点击next即可
23、最后点击“finish”即可完成安装。
