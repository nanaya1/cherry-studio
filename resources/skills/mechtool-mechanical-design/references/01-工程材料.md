## 1. 钢铁产品牌号表示方法 (GB/T 221-2008)

### 牌号前缀字母含义（名称/用途/工艺符号）
| 符号 | 含义 | 符号 | 含义 |
|------|------|------|------|
| Q | 碳素结构钢/低合金高强度钢(屈服强度"屈") | T | 碳素工具钢 |
| H(牌号头) | 焊接用钢 | G(牌号头) | 轴承钢(滚) |
| Y | 易切削钢 | SM | 塑料模具钢 |
| R(牌号尾) | 压力容器用钢 | g(小写尾) | 锅炉用钢 |
| q(小写尾) | 桥梁用钢 | L(尾) | 汽车大梁用钢 |
| NH | 耐候钢 | Z/ZG | 铸钢 |
| HT | 灰铸铁 | QT | 球墨铸铁 |
| KTH/KTB | 可锻铸铁 | A(尾) | 高级优质钢 |
| E(尾) | 特级优质钢 | F(尾) | 沸腾钢 |
| Z/b/TZ | 镇静/半镇静/特殊镇静钢 | A/B/C/D/E | 质量等级 |

### 常见牌号解读规则
- **碳素结构钢**: Q235B = 屈服强度 235MPa, B级质量。Q345C 同理（低合金）
- **优质碳素结构钢**: 数字=平均含碳量万分数。08F(含碳0.08%,沸腾钢)、45(0.45%C)、40Mn(较高锰)、20g(锅炉)
- **合金结构钢**: 数字(含碳量万分数)+元素符号+含量数字。30CrMnSi=0.30%C Cr/Mn/Si<1.5%；20Cr2Ni4=Cr 1.5~2.49%(标2)、Ni 3.5~4.49%(标4)；尾部 A=高级优质
- **碳素工具钢**: T9、T12A = 含碳量千分数, A高级优质；T8Mn 较高锰
- **合金工具钢/高速钢**: Cr12MoV(≥1.0%C 不标含碳)；W6Mo5Cr4V2 高速钢头部不标碳；Cr06(低铬<1%)
- **轴承钢**: GCr15 = 铬含量千分之1.5%的轴承钢(高碳铬)；G20CrNiMo=渗碳轴承钢
- **不锈钢/耐热钢**: 数字=含碳量万分数(上限≤0.10%时用上限3/4表示,如06=0.08%上限)。06Cr19Ni10=0Cr18Ni9(旧)即304；022Cr19Ni10=00Cr19Ni10(304L)；12Cr18Ni9=1Cr18Ni9(302)；Y12Cr18Ni9 易切削
- **铸钢**: ZG200-400 = 屈服200MPa/抗拉400MPa；ZG20Cr13 合金铸钢

## 2. 常用钢力学性能与用途

### 碳素结构钢 (GB/T 700-2006) — Q195/Q215/Q235/Q275
- **Q235**: σs≥235MPa, σb 370~500MPa。最常用普通结构钢。A/B级用于一般构件，C/D级用于重要焊接结构。用于型钢、钢板、螺栓、焊接件、机架等非关键件

## 3. 铸铁

### 灰铸铁 (GB/T 9439)
- 牌号数值 = φ30mm 单铸试棒最小抗拉强度(MPa)
- **HT100~HT350**：抗压强度为抗拉的 3~4 倍，吸振减振性好
- 壁厚增大 → 强度下降(凝固冷却慢)，设计时按实际壁厚查表
- 硬度与强度经验关系: σb≥196MPa 时 HB=RH(100+0.438σb)；σb<196MPa 时 HB=RH(44+0.724σb)，RH=0.8~1.2
- **用途**: HT150 一般底座/端盖/阀壳; HT200 汽缸/齿轮/床身(中等强度,需人工时效); HT250 阀壳/油缸/联轴器; HT300/350 高强耐磨件/高压液压件/机床导轨
- 滑动摩擦条件下不宜用普通灰铸铁,应选低合金灰铸铁(含P/Cr/Mo/Cu)
- 不宜在 300~400℃ 以上长期使用；壁厚悬殊件不推荐

### 球墨铸铁 (GB/T 1348)
- QT400-18 / QT450-10 / QT500-7 / QT600-3 / QT700-2 / QT800-2：第一组数字=σb, 第二组=δ%
- 强度接近钢、保留铸铁工艺性：曲轴、凸轮轴、齿轮、阀体、管件(可代锻钢件)

## 4. 有色金属

### 变形铝及铝合金牌号 (GB/T 16474, 四位数字体系)
- **1xxx** 工业纯铝(≥99%)：导电导热、耐蚀，强度低
- **2xxx** Al-Cu系(硬铝)：高强度。2A12(LY12)航空结构件；2A11(LY11)
- **3xxx** Al-Mn系：防锈铝，中等强度，散热器、油箱(3003)
- **4xxx** Al-Si系：焊接材料、耐磨件(4032活塞)
- **5xxx** Al-Mg系(防锈铝)：强度中高、耐蚀焊接好(5052、5083船用/压力容器)
- **6xxx** Al-Mg-Si系：**挤压型材主流**(6061、6063门窗幕墙)，可热处理强化
- **7xxx** Al-Zn系(超硬铝)：最高强度(7075、7A04航空结构)
- 状态代号: O退火 / H加工硬化(H14半硬) / T6固溶+人工时效 / T4固溶+自然时效

### 常用铸造铝合金 (GB/T 1173)
- ZL101/ZL102(Al-Si)铸造性好：壳体、缸体；ZL104 较好综合性能；ZL105 高温强度；ZL201(Al-Cu)高强度；ZL301(Al-Mg)耐蚀

### 铸造铜合金 (GB/T 1176)
- **ZCuSn10P1**(锡青铜)：耐磨，轴套、蜗轮(高速重载)
- **ZCuSn5Pb5Zn5**(5-5-5锡青铜)：通用轴瓦
- **ZCuAl10Fe3**(铝青铜)：高强度耐磨耐蚀，大型轴套、蜗轮、齿轮
- **ZCuZn38**(黄铜)：一般结构件、阀体
- 加工铜: H62/H68黄铜(紧固件、管件)、HPb59-1铅黄铜(易切削)、QSn6.5-0.1锡青铜(弹簧)、QBe2铍青铜(导电弹性)

### 钛及钛合金
- TA2工业纯钛(耐蚀)、TC4(Ti-6Al-4V)α+β型最常用：航空结构、医用植入、化工耐蚀(强度高密度小)

## 5. 热处理与表面处理

### 钢的普通热处理
| 工艺 | 加热温度 | 冷却 | 目的 |
|------|---------|------|------|
| 退火 | Ac₃+20~30℃(完全) | 炉冷 | 降低硬度利切削、细化晶粒、消除内应力 |
| 正火 | Ac₃+30~50℃ | 空冷 | 细化组织、调整硬度(低碳钢代退火) |
| 淬火 | Ac₃/Ac₁+30~50℃ | 水/油冷 | 获得马氏体,提高硬度耐磨性 |
| 回火 | 低温150~250℃ | 空冷 | 淬火后去应力(硬度60HRC左右,工具) |
| 中温回火350~500℃ | | | 弹性件(弹簧)45~50HRC |
| 高温回火500~650℃(调质) | | | 综合力学性能(轴/齿轮)22~32HRC |

### 表面热处理
- **表面淬火**: 火焰/感应(高频/中频)——中碳钢齿轮/轴表面硬化,心部韧
- **渗碳**: 低碳钢(20CrMnTi)850~950℃渗碳+淬火,表面 58~62HRC 耐磨,用于传动齿轮
- **渗氮(氮化)**: 38CrMoAl 500~570℃,表面 ≥850HV,变形极小——精密主轴、镗杆
- **碳氮共渗**: 兼有渗碳渗氮优点,温度低变形小

### 表面处理技术
- **电镀**: 镀锌(防锈)、镀铬(耐磨/装饰/修复)、镀镍(耐蚀)、镀铜(打底)
- **化学镀**: 镀镍(均镀性好,复杂件)
- **热浸镀**: 热浸锌(钢铁件防锈,大气环境寿命长)
- **阳极氧化**: 铝合金表面(硬质阳极氧化耐磨、着色装饰)
- **发蓝/磷化**: 钢铁防锈膜层
- **喷丸/滚压**: 表面强化,提高疲劳强度(喷丸可提高20%)
- **陶瓷涂层**: 耐高温耐磨隔热
