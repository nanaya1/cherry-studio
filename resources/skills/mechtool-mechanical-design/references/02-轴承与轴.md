## 1. 滚动轴承分类(GB/T 271)

### 1.1 分类方法

| 分类方法 | 类别 |
|---------|------|
| 按载荷方向/公称接触角 α | 向心轴承(α≤45°：径向接触 α=0°、角接触向心 0°<α≤45°)；推力轴承(α>45°：轴向接触 α=90°、角接触推力 45°<α<90°) |
| 按滚动体种类 | 球轴承 / 滚子轴承(圆柱、滚针、圆锥、调心滚子) |
| 按滚动体列数 | 单列 / 双列 / 多列 |
| 按能否调心 | 调心轴承(球面滚道) / 非调心(刚性)轴承 |
| 按部件能否分离 | 可分离轴承 / 不可分离轴承 |
| 按外径 D | 微型 D≤26；小型 28~55；中小型 60~115；中大型 120~190；大型 200~430；特大型 ≥440 |

### 1.2 综合分类树

```
滚动轴承
├─ 向心轴承
│  ├─ 径向接触球轴承 ── 深沟球轴承
│  ├─ 径向接触滚子轴承 ── 圆柱滚子轴承、滚针轴承
│  ├─ 角接触向心球轴承 ── 调心球轴承、角接触球轴承
│  └─ 角接触向心滚子轴承 ── 圆锥滚子轴承、调心滚子轴承
├─ 推力轴承
│  ├─ 轴向接触球轴承 ── 推力球轴承
│  ├─ 轴向接触滚子轴承 ── 推力圆柱滚子轴承、推力滚针轴承
│  ├─ 角接触推力球轴承 ── 推力角接触球轴承
│  └─ 角接触推力滚子轴承 ── 推力圆锥滚子轴承、推力调心滚子轴承
└─ 组合轴承(滚针+推力球/推力角接触球/推力圆柱滚子等)
```

### 2.2 类型选择要点

- **转速**：球轴承极限转速 > 圆柱滚子 > 圆锥/调心滚子 > 推力轴承；同尺寸下径向承载能力滚子 > 球。
- **载荷方向**：纯径向→深沟球/圆柱滚子/滚针；径向+单向轴向→角接触球/圆锥滚子(成对或面对面安装)；径向+双向轴向→双列角接触/一对角接触/深沟球(轻轴向)；纯轴向→推力轴承；大轴向+径向联合→推力调心滚子。
- **调心需求**：轴长、挠度大、两座孔难对中→调心球/调心滚子；调心滚子不能承受纯轴向。
- **安装拆卸频繁**：选可分离型(圆柱滚子、圆锥滚子、四点接触、推力轴承)。
- **径向尺寸受限**：滚针轴承；轴向尺寸受限：推力滚针组件(轴向占用最小)。
- **游动支承**：NU型圆柱滚子最宜；角接触球不宜作游动支承。
- 调心球轴承(额定动载荷比0.6~0.9)、调心滚子轴承(2.3~5.2)、圆柱滚子轴承中 **双列(2.6~5.2)、四列(4.5~6)** 承载能力最大。

### 2.4 基本代号构成说明 (GB/T 272-1993 体系)

滚动轴承代号由**基本代号 + 前置代号 + 后置代号**组成(标准原文为图示，本表由各类型页型号归纳)：

- **基本代号** = 类型代号 + 尺寸系列代号 + 内径代号。常见如 6205：6(深沟球类型) + 2(宽度系列 0 省略，尺寸系列 2) + 05(内径 05×5=25mm)。内径代号：00=10、01=12、02=15、03=17；04~96 用"内径数字×5"(如 05=25mm)；≥500mm 及 22/28/32 等非标准用斜线直接标内径(如 62/22=d22、618/9=d9、617/0.6=d0.6mm)；d=10~17mm 的微型轴承内径代号为 00~03 规则。
- **尺寸系列**体现直径系列与宽度系列：深沟球 618/619(超轻)、16000(特轻)、6000(轻窄)、6200(轻宽，即(0)2 系列)、6300(中宽(0)3)、6400(重(0)4)；调心球 1200/2200(轻)、1300/2300(中)；调心滚子 21300(轻窄)、22200(轻宽)、22300(中宽)、23000/23100/23200(特宽系列)；角接触 71900/7000(轻)、7200(中)、7300(重)；圆锥 30200/32200/32000(轻)、30300/32300(中)、31300(大锥角)；圆柱 NU200(轻窄)、NU300(中宽)、NU2200/NU2300(加强)。
- **后置代号**(结构变化/公差/游隙/材料等，从特性与型号页归纳)：C=15°角接触、AC=25°、B=40°(角接触球)或 B=加强型(调心滚子早期)；E=加强型(圆柱滚子)；K=锥孔 1:12、K30=1:30；-Z/-2Z 防尘盖、-RS/-2RS 接触式密封、-RZ/-2RZ 非接触密封(深沟球)；N=止动槽、NR=止动槽+止动环；TN/TN1=尼龙保持架、M=黄铜实体保持架、CC=钢板冲压架(调心滚子)；W33=外圈油槽+3 油孔；/DB、/DF、/DT=成对背对背/面对面/串联；P0~P6/P5/P4/P2=公差等级；C2/0/C3/C4/C5=游隙组别。
- **前置代号**：K-、L-、R- 等(如推力调心滚子前置 GS/WS 座圈、K 表示滚子组)及关节轴承类型字母 G 系列代号。
- **磁电机轴承**用基本代号+后置代号 E/EN(公差、材料)；**内燃机水泵轴连轴承**用七位数字及 T(螺纹轴)/F(扁面)/K(键槽)/R(钻孔)/Y(结构特殊)后缀(如 WB 两列球、WR 一列滚子一列球型)。

> 注：GB/T 272 原代号表为图示资料，以上由语料各类型页与 GB/T 272-1993 体系归纳，具体标注请以 GB/T 272 现行版与制造厂样本为准。

### 2.5 专用轴承简介

- **机床轴承**：双向推力角接触球轴承(230000 型)与双列圆柱滚子轴承用于主轴；预加载荷在公差等级代号后加组别，特殊预紧用 G+预紧力数值(N)。
- **磁电机轴承**：基本代号+后置 E/EN，内径用毫米数表示。
- **水泵轴连轴承**(内燃机)：轴连轴承结构，WB(两列球)、WR(一列滚子一列球)等。
- **回转支承(JB/T 2300-2011/2018)**：单排四点接触球式(01)、双排异径球(02)、单排交叉滚柱(03)、三排滚柱(04)等型式+内/外齿；标记示例："回转支承 014.40.1000.10 JB/T 2300"(型式 014、滚动体直径 40mm、节圆直径 1000mm、齿轮模数 10)。

## 4. 滚动轴承的当量载荷与寿命计算

### 4.1 基本额定寿命 (GB/T 6391)

```
                    (C/P)^ε
基本额定寿命 L10 = (──────) × 10^6 转
                      1

以小时计:  L10h = 10^6/(60n) · (C/P)^ε   (h)

C  —— 基本额定动载荷(kN，产品表查得)
P  —— 当量动载荷(kN)
n  —— 转速(r/min)
ε  —— 寿命指数：球轴承 ε=3；滚子轴承 ε=10/3
```

### 4.2 径向当量动载荷

**深沟球轴承**：Pr = X·Fr + Y·Fa
- 单列轴承：当 Fa/Fr ≤ e 时 X=1、Y=0(即 Pr=Fr)；当 Fa/Fr > e 时按 e 值取 X=0.56，Y=1.04~2.3(f0·Fa/C0r 越小 Y 越大；e=0.19~0.44 与 f0·Fa/C0r 相关，f0 见 GB/T 4662)。
- 双列轴承：Fa/Fr≤e 时 X=1、Y=0.95~2.3(同 f0Fa/C0r 档)；>e 时 X=0.56。
- 径向当量**静**载荷：P0r = 0.6Fr + 0.5Fa；当 P0r < Fr 时取 P0r = Fr。

**角接触球/圆锥滚子轴承**：Fa 需计入轴承内部派生轴向力，成对安装按力平衡求各轴承 Fa，再按 X、Y 系数(表列 e、Y 值，如圆锥滚子 30205: e=0.37、Y=1.6、Y0=0.9)计算。

### 4.3 修正额定寿命 (GB/T 6391-2010)

```
Lnm = a1 · aiso · L10
```
- a1 — 可靠度寿命修正系数：可靠度 90%→1、95%→0.64、96%→0.55、97%→0.47、98%→0.37、99%→0.25、99.2%→0.22、99.4%→0.19、99.6%→0.16、99.8%→0.12、99.9%→0.093、99.92%→0.087、99.94%→0.080、99.95%→0.077。
- aiso — 寿命修正系数，综合轴承类型、材料(洁净度/硬度/表面结构/疲劳极限/温度响应)、润滑(黏度/转速/尺寸/添加剂)、污染、杂质颗粒、套圈内应力、安装(损伤/不同心)等，计算方法见 GB/T 6391-2010，具体数值通常与制造厂商议。

注：调心球、调心滚子、推力调心滚子、推力圆锥滚子仅生产 0 级；圆锥滚子一般只生产 0 级。精密轴承须与轴、壳孔形位公差及表面粗糙度协调才能发挥效能。公差等级代号标注于轴承代号之后，如 6205/P6。

### 5.2 配合选择要点

- 内圈与轴旋转(载荷相对内圈旋转)或重载时选过盈配合(k5/m5…)，静止时可选过渡/间隙配合。
- 基本组游隙(0组)轴承的配合范围(参考)：球轴承轴 j5…k5，滚子/滚针轴承轴 k5…m5；外壳孔球轴承 J6，滚子轴承 K6。
- 旋转的套圈(转动载荷)应比静止套圈采用更紧的配合。
- 游隙：过盈配合安装使内圈膨胀/外圈收缩→游隙减小；运转温差使游隙变化。球轴承运转温度下游隙宜接近零；滚子轴承宜保留一定径向游隙。非调整式轴承(深沟球、圆柱滚子)游隙由厂方选配，用户选游隙组别即可；角接触球、圆锥滚子等调整式轴承安装时须调整轴向游隙。
- 重冲击、大过盈、内圈温度高→选大游隙(3、4组…)；振动噪声/精度要求高→选小游隙(2组)。径向游隙标准 GB/T 4604.1-2012；四点接触球轴向游隙 GB/T 4604.2-2013。

## 6. 滚动轴承组合设计与支承结构

### 6.1 轴承配置基本型式

| 型式 | 特点与应用 |
|------|-----------|
| 背对背(DB) | 载荷作用中心在轴承中心线之外，跨距大、悬臂端刚性好；轴受热伸长时游隙增大，不会卡死；预紧安装时热伸长使预紧量减小 |
| 面对面(DF) | 载荷作用中心在内侧，结构简单装拆方便；轴热伸长时游隙减小易卡死，须注意游隙调整 |
| 串联(DT) | 载荷作用中心同侧，用于单向轴向载荷大、需多轴承联合承载 |
| 两端固定支承 | 各限制一个方向轴向位移；用于纯径向或轴向载荷较小的轴；一端外圈留间隙适应热伸长 |
| 固定-游动支承 | 固定端轴向定位(定位精度取决于其游隙)，游动端(常用NU圆柱滚子)允许轴向移动；适应性强，广泛用于机床主轴、蜗杆轴、长轴 |
| 两端游动支承 | 轴向位置由其它零件限定(如人字齿轮轴) |

固定端轴承选择：径向+一定轴向→深沟球；径向+双向轴向→一对角接触球或圆锥滚子；径向与轴向分承→向心+推力组合。

### 6.2 轴向紧固方法

**内圈紧固**：轴肩(承受单向轴向力、结构简单)、弹性挡圈(轴向尺寸小、载荷不大)、圆螺母+止动垫圈(可承受较大轴向载荷)、轴套+其它零件压紧(同时固定多个零件)、轴端挡圈+螺栓铁丝(轴端不便切螺纹时)。
**锥孔轴承在光轴上的紧固**：带挡边套筒+端盖、紧定衬套(转速不高、轴向载荷不大)、退卸套、直接装锥形轴颈。
**外圈紧固**：弹性挡圈(孔用)、止动环+轴承盖(外圈带止动槽)、轴承盖(凸肩，可承受较大轴向载荷)、带螺纹开口轴承盖(径向尺寸小处)、衬套+轴承盖(壳体通孔、可调轴向尺寸)、轴承盖+压盖+调节螺钉(向心推力轴承调游隙)、双压环(内孔不能加工凸肩时)。
**轴肩尺寸**：轴肩高 a=(0.07~0.1)d(与滚动轴承配合处按轴承安装尺寸确定)，应使 r<c 或 r<R；轴环宽 b≈1.4a。

### 6.3 滚动轴承的润滑

脂/油选择原则：

| 因素 | 用润滑脂 | 用润滑油 |
|------|---------|---------|
| 温度 | 超120℃用特殊脂；200~220℃须缩短补脂周期 | 油池>90℃或轴承>200℃用特殊油 |
| dn 值界限 | 球<160000；圆柱/圆锥<100000~120000；调心滚子<80000；推力球<40000 | 球轴承油浴<250000、滴油<400000、循环<600000；圆锥/调心滚子油浴<120000~160000、循环<250000~300000；推力球油浴<60000 |
| 载荷 | 低~中等 | 各种载荷直至最大 |
| 免维护场合 | 可用(注意工作温度) | 不可用 |

dn = 轴承内径(mm)×转速(r/min)；大轴承(直径>65mm)用 dmn(dm 为内外径平均值)。转速高、需散热、集中供油时选油润滑；简单密封、长期免维护、防污染选脂润滑。

### 6.4 滚动轴承的密封

**非接触式**(无摩擦、无磨损、可用于高速)：
- 缝隙式：径向间隙 0.1~0.3mm，环境干净脂润滑；
- 沟槽式：端盖开 3 条以上宽 3~4mm、深 4~5mm 沟槽填脂；
- 螺旋沟槽式：螺旋方向与轴旋向相反，把外泄油送回；
- W 形沟槽式：油润滑甩油回收；
- 迷宫式(轴向/径向/斜向/组合)：曲路越多越可靠，用于脏环境；径向迷宫端盖须剖分，斜向迷宫适于轴摆动大的调心支承。

非接触密封间隙(mm)：轴径<50：径向 0.1~0.4、轴向 1~2；轴径≥50：径向 0.5~1.0、轴向 3~5。

**接触式**(有磨损发热)：毡封式(脂润滑干净环境，圆周速度≤4~5m/s，抛光轴可达7~8m/s，温度≤90℃；宜用轴套与毡接触保护轴)；油封/皮碗式(耐油橡胶，圆周速度≤7m/s，-40~100℃；唇口朝轴承防漏油、朝外防尘，双向用两只对装)。
**综合式**：粉尘水分多、不允许泄漏场合组合使用。

### 8.1 分类

| 分类依据 | 类别 |
|---------|------|
| 承载方向 | 径向 / 止推(推力) / 径向止推 |
| 结构 | 整体式 / 剖分式 / 自位式 |
| 润滑(摩擦)状态 | 流体润滑 / 非完全流体润滑 / 无润滑(干摩擦) |

| 载荷 | 轻载 p<1MPa；中载 1~10MPa；重载 >10MPa |

### 8.2 各类型性能比较(选择要点)

| 项目 | 一般滑动轴承 | 含油轴承 | 液体动压 | 液体静压 | 气体静压 | 无润滑轴承 | 滚动轴承 |
|------|------------|---------|---------|---------|---------|-----------|---------|
| 润滑 | 脂/油绳/滴油，油膜不连续 | 本身含油 | 需油量较多 | 需专用压力供油系统 | 需洁净气源 | 不加润滑剂 | 脂润滑简单 |
| 适用速度 | 低中速 | 低中速 | 中高速 | 极低~高速 | 极低~高速 | 低速 | 低中速(高速需特殊) |
| 径向定位精度 | 较高 | 较高 | 高 | 极高 | 高 | 差 | 高 |
| 运转平稳性 | 好 | 好 | 很好 | 极好 | 极好 | 可以 | 好 |
| 噪声 | 小 | 小 | 小 | 小 | 小 | 小 | 较大 |

要点：液体动压轴承能短时承受相当大的过载，常用于载荷不平稳场合；空气动压轴承 pmax 一般<0.035MPa；静压轴承承载和刚度高于动压空气轴承；无润滑/含油轴承在 300~1500r/min 内承载高于空气静压轴承。

### 8.3 不完全流体润滑径向轴承验算

工况：脂/滴油/油绳/油垫润滑或自润滑材料，处于混合/边界润滑。选用原则：载荷方向应在轴承中心线左右 35°范围内；可通过轴肩承受不大轴向载荷(轴肩直径≥轴瓦肩外径时轴向载荷≤最大径向载荷 30%)。

```
轴承平均压强:   p = P/(B·d)     ≤ [p]
pv 值:          pv = p·v        ≤ [pv]
轴颈圆周速度:   v = π·d·n/60000 ≤ [v]     (m/s)
P — 径向载荷 N；d — 轴颈直径 mm；B — 轴承工作宽度 mm；n — 转速 r/min
[p]、[pv]、[v] — 许用值，按轴承材料表选取
```

止推滑动轴承：空心止推轴承取 d1=0.5d2(或 0.4~0.6d2)时接触面压强分布最均匀；环形止推轴承 b=(0.1~0.3)d1、h=(0.12~0.15)d1、d2=(1.2~1.6)d1；实心止推中心压强理论上无穷大，不推荐。
自润滑镶嵌轴承(金属基体镶固体润滑剂，初次使用抹脂)：ZRHQ(基体 ZCuSn5Pb5Zn5，允许载荷 15MPa/速度 25m/min 不加油，pv 60)、ZRHH(基体 ZCuZn25Al6Fe3Mn3，25MPa、pv100)、ZRHT(基体 HT200，5~8MPa)；摩擦因数 0.06~0.25，工作温度可达 400℃(ZRHQ 不加油)。适合免维护、往复摇摆、频繁启停、重载低速、水/腐蚀环境。

## 9. 轴的设计

### 9.1 轴的分类

| 按受载 | 说明 |
|--------|------|
| 转轴 | 支承传动件又传递动力：同时受扭矩和弯矩 |
| 心轴 | 只支承回转件不传动力：只受弯矩。固定心轴(不转动)/转动心轴 |
| 传动轴 | 主要传递动力：主要受扭矩 |

按形状：光轴/阶梯轴、实心/空心；按轴线：直轴、曲轴、钢丝软轴。

### 9.2 设计程序

① 确定轴上零件布置与装配方案 → ② 选材料 → ③ 按纯扭估算轴径 → ④ 结构设计(轴肩/键槽/圆角) → ⑤ 强度、刚度计算 → ⑥ 必要时精确校核 → ⑦ 高转速、大跨距、长外伸轴做临界转速校核 → ⑧ 不满足则改进结构再验算 → ⑨ 绘制工作图。遵循"结构设计→承载验算→结构改进→再验算"循环。
轴的结构设计考虑：受力合理(扭矩分流、弯矩分配)、减轻质量等强度外形、定位可靠(轮毂应长出轴段 2~3mm)、减少应力集中、工艺结构要素(中心孔/退刀槽/越程槽)、键槽尽量同向同尺寸、便于装拆(倒角、无过盈装配到位)、刚度、精度与配合合理、符合标准件尺寸。

### 9.3 轴的常用材料

材料表为图片(见语料原页)；常用轴材料：Q235-A/20、Q275/35、45、1Cr18Ni9Ti、40Cr/35SiMn/42SiMn/40MnB/38SiMnMo/3Cr13 等，其扭转许用应力与 A 值见下表(强度计算用)。

### 9.4 按扭转强度/刚度初估轴径

轴强度计算三种情况：①按扭转强度或刚度计算(只传转矩或弯矩不大、跨距载荷未定时降低许用应力估算)；②按弯扭合成强度；③精确强度校核。

**扭转强度估算实心轴径**（通用公式，源自 τ=T/Wt）：

```
        ┌─────
d ≥ A·³√(P/n)      (mm)
P — 功率 kW；n — 转速 r/min
空心轴: d ≥ A·³√(P/(n(1-α⁴)))，α=d1/d(内径/外径)
τ = T/Wt ≤ [τ] 验算: T=9549P/n (N·m)
```

常用轴材料 [τ]/MPa 与 A 值：

| 轴材料 | Q235-A、20 | Q275、35、(1Cr18Ni9Ti) | 45 | 1Cr18Ni9Ti | 40Cr、35SiMn、42SiMn、40MnB、38SiMnMo、3Cr13 |
|--------|-----------|----------------------|-----|-----------|----------------------------------------------|
| [τ]/MPa | 15~25 | 20~35 | 25~45 | 15~25 | 35~55 |
| A | 149~126 | 135~112 | 126~103 | 148~125 | 112~97 |

注：表中 [τ] 为考虑弯曲影响降低后的许用扭转切应力；弯矩小/载荷平稳/无轴向力/单向旋转/低速轴时 [τ] 取大值、A 取小值。减速器中间轴(装小齿轮处)45 钢可取 A=130~165(二级中间轴及三级高速中间轴取 155~165，三级低速中间轴取 130)。截面有键槽时轴径应增大(单键约 3%~5%、双键约 7%~10%，具体见表"有键槽时轴径的增大值")。

**按扭转刚度**(G=79.4GPa 钢轴)：

```
光轴许用扭转角公式(每米):  φ = 584·T·l/(G·d⁴) 型（T 与 d 单位换算后）
简化实用式:  d ≥ B·⁴√(P/n)  （B 值见表）
φp(°)/m: 0.25 | 0.5 | 1 | 1.5 | 2 | 2.5
B:        129  | 109 | 91.5 | 82.7 | 77 | 72.8
```

许用扭转角选取：精密稳定传动 0.25~0.5(°)/m；一般传动 0.5~1(°)/m；要求不高 >1(°)/m；起重机传动轴 15'~20'/m；重型机床走刀轴 5'/m。

### 9.5 轴的刚度校核

**扭转刚度**：以每米轴长扭转角 φ 度量。φ 过大影响性能与精度(如凸轮轴气门启闭、起重机运行机构驱动轮同步)。公式适用 G=79.4GPa 钢轴；钢 G≈8.1×10⁴ MPa。

**弯曲变形许用值**：

| 变形 | 位置/工况 | 许用值 |
|------|----------|--------|
| 挠度 y | 一般用途轴 | [y]=(0.0003~0.0005)L |
| | 刚度要求高 | [y]=0.0002L |
| | 安装齿轮处 | [y]=(0.01~0.03)mn(法向模数) |
| | 安装蜗轮处 | [y]=(0.02~0.05)ms |
| | 感应电动机轴 | [y]≤0.1δ(气隙) |
| 偏转角 θ | 滑动轴承处 | 0.001 rad |
| | 深沟球轴承处 | 0.005 rad |
| | 调心球轴承处 | 0.05 rad |
| | 圆柱滚子轴承处 | 0.0025 rad |
| | 圆锥滚子轴承处 | 0.0016 rad |
| | 安装齿轮处 | 0.001~0.002 rad |

### 9.6 轴的临界转速校核

- 轴系是弹性体，材料不均/制造安装误差致重心偏移，回转时产生离心强迫振动；强迫频率接近自振频率即共振，对应转速称临界转速。
- 振动类型：横向(最常见)、扭转、纵向。转速低于一阶临界转速为刚性轴(n<0.75ncr1)，高于一阶为挠性轴(n>1.4ncr1 且 n<0.7ncr2)；机械多用刚性轴，离心机/汽轮机高速轴常采用挠性轴以减小直径。
- 均匀质量光轴横向振动一阶临界转速通用式：ncr ∝ λ²·√(EI/(W0·L³))(λ 为支座形式系数：简支-简支 λ1=9.87、悬臂 λ1=3.52、两端固定 λ1=22.37 等，E 钢≈206×10³MPa)；带圆盘不计轴自重时按集中质量公式。
- 阶梯轴近似按当量直径 dv 的光轴计算(dv 由各段 di、Δli 加权，ξ 经验修正系数：最粗段长>全长50%取 ξ=1；压缩机/离心机/鼓风机转子常取 ξ=1.094)。
- 临界转速与空间位置(垂直/水平)无关。

### 9.7 轴系附件与特殊轴

- **零件轴向定位与固定**：轴肩/轴环(定位可靠，a=0.07~0.1d，b≈1.4a，应 r<c 或 r<R)、套筒(定位可靠不影响疲劳强度，宜短距离，高速不宜)、轴端挡板(心轴端，GB/T 892)、弹性挡圈(GB/T 894，力小)、紧定螺钉(GB/T 71，力小低速)、锁紧挡圈(GB/T 884)、圆锥面(消除径向间隙、兼周向固定、承受冲击，配压板/螺母双向固定，轮毂长出锥段 2mm)。
- **曲轴设计要点**：满足强度刚度、减少应力集中与挠曲、提高自振频率避开共振、争取较大轴颈重叠度和减小跨度、尽量减小平衡块质量；保证主轴承/连杆轴承承压面积与润滑、油孔布置合理；曲柄排列错角均等、平衡块配置合理、尽量对称以满足动平衡、改善扭振。
- **软轴(钢丝软轴)**：由多层钢丝卷绕而成，用于两轴不在同一直线或有相对运动的传动；由软轴本体、软管、接头(软轴接头/软管接头)组成；选择按传递转矩、转速、弯曲半径、长度确定规格，使用时弯曲半径不小于规定值，注意转向(软轴有规定旋向，一般只能单向传递较大转矩)、防逆转装置用于防止反转松脱。规格结构与典型结构见语料原页。
- 曲轴强度计算分弯扭合成与精确校核(见语料"曲轴的强度计算"页，图解法确定支反力与危险截面)。

### 10.2 联轴器选用计算 (JB/T 7511-1994)

```
计算转矩:  Tc = T·Kw·K·Kz·Kt ≤ Tn(公称转矩)
理论转矩:  T = 9550·Pw/n  (N·m)   [Pw—驱动功率 kW，n—转速 r/min]
Kw — 动力机系数: 电动机、透平机 1.0；四缸及以上内燃机 1.2；二缸 1.4；单缸 1.6
K  — 工况系数(按工作机载荷类别查表: 均匀载荷如离心泵、转向机构 1.0~；回转泵 1.5 等)
Kz — 启动系数: 启动频率≤120次/h 取 1.0；120~240次/h 取 1.3；>240次/h 由制造厂定
Kt — 温度系数(查表)
```

注意事项：需要减振、缓冲、改善对中时选弹性联轴器，且系统内联轴器应为唯一弹性部件；配制动器的系统当制动器理论转矩大于动力机理论转矩时，按制动器转矩选联轴器。

### 10.3 联轴器轴孔与连接型式 (GB/T 3852-1997)

- 轴孔型式：Y 型(长圆柱形)、J 型(有沉孔短圆柱形)、J1 型(无沉孔短圆柱形)。
- 键槽型式：A 型(平键单键槽)、B 型(120°双键槽)、B1 型(180°双键槽)、D 型(切向键槽)。
- 轴孔直径 d(H7)与键槽尺寸(键宽 b、深 t/t1 等)按标准表配合(如 d=6~10 配键 b=2~3；d 增大键宽随之增大)；Y 型长度 L 大于 J/J1 型。标记示例：如 "GY6 凸缘联轴器 Y48×112/J1 42×84 GB/T 5843" 类，轴孔直径与长度按 GB/T 3852 选。

## 11. 设计选用要点与常见错误

1. **载荷计算错误**：角接触球、圆锥滚子轴承成对使用时忘记计入派生轴向力；Fa/Fr 判据选错 X/Y 系数(注意 e 随 f0·Fa/C0r 变化)。
2. **转速判断**：误把脂润滑极限转速当油润滑使用；dn 值超限导致温升烧毁——高速选油润滑/循环润滑。
3. **游隙选择不当**：大过盈/温差大仍用 0 组游隙导致卡滞；或精度要求高却用大游隙组导致振动噪声。
4. **配合与公差等级不匹配**：精密轴承配普通精度轴颈、形位公差与粗糙度不协调，精密等级白选。
5. **轴向定位不可靠**：弹性挡圈用于大轴向力；忘记留热伸长间隙(面对面配置尤甚)；游动端误用不能轴向游动的轴承。
6. **调心轴承选型**：把调心滚子轴承用于纯轴向载荷(不允许)；两座孔不对中却用刚性轴承。
7. **轴设计**：初估轴径后未按键槽修正；忽略应力集中(圆角过小、键槽尖角)；临界转速校核遗漏(高速细长轴、长外伸端)；热膨胀未考虑。
8. **联轴器**：不乘工况系数/启动系数直接按理论转矩选；需缓冲减振却选刚性联轴器；忽略轴孔型式与键槽规格匹配。
9. **润滑密封**：密封形式与润滑方式不匹配(毡封用于油润滑易漏)；迷宫式用于很脏环境但曲路数不足。
10. 数据追溯：本节尺寸与载荷为 d=10~60mm 常用段节选(标准 GB/T 276-2013 等现行版)，更大尺寸、其它系列请查语料库原页或现行标准原文。
