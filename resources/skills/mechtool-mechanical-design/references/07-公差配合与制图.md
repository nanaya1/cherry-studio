# 公差配合与几何公差速查

> 来源: mechtool.cn (GB/T 1800.1-2020 极限与配合、GB/T 1184-1996 形位公差、GB/T 1182-2018 几何公差)

## 1. 基本概念 (GB/T 1800.1)

- **基本尺寸**: 设计给定的尺寸（计算偏差的基准）
- **极限尺寸**: 允许的最大/最小尺寸；实际尺寸必须位于其间
- **偏差**: 实际/极限尺寸减基本尺寸的代数差
  - 孔: 上偏差 **ES**、下偏差 **EI**；轴: 上偏差 **es**、下偏差 **ei**
- **尺寸公差**: 最大极限尺寸−最小极限尺寸 = 上偏差−下偏差（无符号绝对值）
- **标准公差等级 IT**: 同等级对所有基本尺寸具有同等精确程度。IT01~IT18，数字越大越松
- **基本偏差**: 确定公差带相对零线位置的那个极限偏差（一般指靠近零线的一个）
- **配合**: 基本尺寸相同的孔轴公差带之间的关系
  - 间隙配合: 孔公差带在轴公差带之上（恒有间隙，含零间隙）
  - 过盈配合: 孔公差带在轴公差带之下（恒有过盈）
  - 过渡配合: 公差带交叠（可能间隙或过盈）
- **基孔制**: 基准孔 H（EI=0），与不同基本偏差轴组成配合
- **基轴制**: 基准轴 h（es=0），与不同基本偏差孔组成配合
- 轴 = 被包容面（圆柱/非圆柱外表面）；孔 = 包容面（圆柱/非圆柱内表面）

## 3. 基本偏差选用指南（轴 a~zc / 孔 A~ZC）

### 间隙配合（孔在轴上）
- **a/b**: 特别大间隙，应用很少（热机气缸）
- **c**: 很大间隙，缓慢松弛动配合；工作条件差(农机)、装配方便 — H11/c11；高温紧密动配合 H8/c7（内燃机排气阀导管）
- **d**: IT7~11，松转动配合：密封盖、滑轮、空转皮带轮、大直径滑动轴承（透平/球磨机/轧机）
- **e**: IT7~9，明显间隙易转动：大跨距轴承、多支点轴承；高等级 e 轴→大型高速重载支承（涡轮发动机、大型电机、凸轮轴轴承）
- **f**: IT6~8 **一般转动配合首选**：普通油润滑轴承（齿轮箱、小电机、泵转轴）
- **g**: 间隙很小（制造成本高），不推荐转动；IT5~7 精密滑动定位：精密连杆轴承、活塞滑阀、连杆销、钻模导套
- **h**: 间隙配合最小间隙为零，定位/导向精密滑动：H7/h6 精密定位、H8/h7 导向

### 过渡配合（js k m n / JS K M N）
- **js**: 对称偏差，平均间隙，用于定位要求不高、便于装拆：H7/js6
- **k**: 平均间隙略负，**定位配合最常用**：H7/k6（轴承内圈与轴颈、齿轮与轴）——易装拆且定心好
- **m**: 平均过盈较小，需轻压装配：H7/m6（轴承外圈、联轴器）
- **n**: 平均过盈较大，压装：H7/n6（重载齿轮、不可拆连接）

### 过盈配合（p~zc / P~ZC）
- **p**: 最小过盈为零~小过盈，压装（H7/p6 轴承/薄壁套）
- **r/s**: 中等过盈，用压力机压装：H7/r6、H7/s6（铸铁轮毂、衬套）
- **t/u/x**: 大过盈，热装/冷装，传递扭矩不靠键：H7/u6、H7/x6（重载联轴器、齿轮轮毂）
- 过盈量必须校验材料强度与装配方式（压装/热装温差）

### 常用配合应用速查
| 配合 | 性质 | 典型应用 |
|------|------|---------|
| H7/f6 | 间隙(中) | 滑动轴承、齿轮箱转轴 |
| H7/g6 | 间隙(小) | 精密滑动/移动导向 |
| H7/h6 | 间隙(零) | 精密定位、可推入 |
| H7/js6 | 过渡(偏隙) | 定位+易装拆（手锤轻敲） |
| H7/k6 | 过渡(偏盈) | **滚动轴承内圈/齿轮与轴（最常用定位）** |
| H7/m6 | 过渡(偏盈) | 外圈与壳体、需轻压装件 |
| H7/n6 | 过渡(大盈) | 压装、重载齿轮 |
| H7/p6 | 过盈(小) | 压装薄壁套 |
| H7/s6 | 过盈(中) | 铸铁轮毂、衬套(压力机) |
| H7/u6 | 过盈(大) | 热装重载件 |
| H8/e7 | 间隙(大) | 大跨距/多支点轴 |
| H8/d9 | 间隙(大) | 松配合皮带轮、空转轮 |
| H11/c11 | 间隙(很大) | 农机、粗配合 |

## 5. 几何公差标注 (GB/T 1182-2018)

### 特征符号
- **形状公差**(无基准): — 直线度、⌒ 平面度、○ 圆度、⌭ 圆柱度、⧓ 线轮廓度、⧖ 面轮廓度
- **方向公差**(需基准): // 平行度、⊥ 垂直度、∠ 倾斜度
- **位置公差**(需基准): ◎ 位置度、◎(同心) 同轴度、⌖ 对称度
- **跳动**: ↙ 圆跳动、↘ 全跳动
- **附加符号**: Ⓜ 最大实体要求、Ⓛ 最小实体要求、Ⓟ 可逆要求、⊕ 延伸公差带、Ⓢ 自由状态、Ⓛ 基准目标等

### 公差原则
- **独立原则**: 尺寸公差与形位公差分别满足（默认，多数场合）
- **包容要求 ⓔ**: 用最大实体边界控制，保证装配性（单一要素标注ⓔ）
- **最大实体要求 Ⓜ**: 用实效边界控制，有良好工艺经济性（可补偿）
- 选择: 装配质量优先→独立原则；经济性优先→最大实体要求

### 选择方法要点
1. 满足功能前提下选较低公差等级；刚性差零件(细长/薄壁)、距离远孔轴可放宽 1~2 级
2. 形状公差 < 位置公差（如平面度 < 平行度）；轴的形状公差 < 尺寸公差
3. 同一要素: 圆柱度/圆度由轴承配合要求定（同轴度可测圆跳动代替：圆跳动合格→同轴度必合格）
4. 形位公差与尺寸公差等级对应（IT5~6 轴配圆度 5 级等）
5. 加工方法决定可达等级: 普通镗孔圆跳动 4~7 级、圆柱度 6 级等

## 6. 表面结构(粗糙度)

- **Ra 轮廓算术平均偏差**: 最常用。系列值: 0.012, 0.025, 0.05, 0.1, 0.2, 0.4, 0.8, 1.6, 3.2, 6.3, 12.5, 25, 50(μm)
- 选用参考: Ra0.2~0.4 精密配合面/轴承滚道; Ra0.8 一般配合面(IT6~7轴颈); Ra1.6~3.2 一般加工面; Ra6.3~12.5 非配合面/粗加工; Ra25 粗面(铸锻后)
- 标注符号: 去除材料基本符号、不去除材料符号、完整标注(上限值+加工方法+纹理)

## 8. 机械制图规范

### 8.1 图线 (GB/T 4457.4-2002)
| 图线 | 线宽 | 应用 |
|---|---|---|
| 粗实线 | 粗 | 可见轮廓线/棱边线、相贯线、螺纹牙顶线、螺纹终止线、齿顶圆、剖切符号 |
| 细实线 | 细 | 尺寸线/尺寸界线、引出线、剖面线、辅助线、螺纹牙底线、齿根线、重合断面轮廓 |
| 波浪线/双折线 | 细 | 断裂处边界、视图与剖视分界 |
| 细虚线 | 细 | 不可见轮廓线/棱边线 |
| 粗虚线 | 粗 | 允许表面处理的表示线 |
| 细点画线 | 细 | 轴线、对称中心线、分度圆、孔系分布中心线、剖切线 |
| 粗点画线 | 粗 | 限定范围表示线 |
| 细双点画线 | 细 | 相邻辅助零件轮廓、极限位置轮廓、毛坯图中制成品轮廓、中断线 |

- 粗细线宽比 **2:1**；优先组别 0.5/0.7（对应细线 0.25/0.35）
- 同一张图样尺寸线终端只用一种形式（箭头或斜线）

### 8.2 剖面符号与画法 (GB/T 4457.5)
- 金属零件剖面线: 间隔相等、方向相同、与水平成 **45°** 的平行细实线；轮廓与水平成 45° 时改画 30° 或 60°
- 装配图相邻金属件: 剖面线方向相反或间隔不等；同一零件在各视图中方向间隔一致
- ≤2mm 狭小剖面可涂黑；相邻涂黑剖面留 ≥0.7mm 空隙
- 材料类别: 金属材料(通用)/非金属/木材纵横剖面/玻璃/型砂粉末冶金/叠钢片/混凝土/钢筋混凝土/砖/液体 等，剖面符号仅表示材料类别，名称代号另行注明

### 8.3 尺寸注法 (GB/T 4458.4-2003)
基本规定:
- 尺寸线/尺寸界线用细实线；轮廓线、中心线可作尺寸界线但**不能作尺寸线**
- 线性尺寸数字避免在竖直方向 30° 范围内标注；数字不可被图线穿过（不可避免时断开）
- 直径 φ、半径 R（尺寸线过圆心，注在圆弧视图上）、球面 Sφ/SR（螺钉头等不致误解时可省 S）、正方形 □ 或"边长×边长"、板厚 t、参考尺寸加括号、均布 EQS

各类尺寸要点:
- 弦长尺寸线为直线、弧长为圆弧且数字上方加 "⌒"
- 角度: 尺寸界线沿径向、尺寸线为圆弧（圆心为角顶点）、数字一律水平
- 斜度/锥度符号方向与斜度锥度方向一致
- 对称结构可只标一边；断续同一表面用细实线连接后标注一次
- 成组相同要素只标一个 + 数量；同一基准尺寸可坐标式列表

### 8.4 表面结构标注 (GB/T 131-2006)
完整符号组成位置:
- **a**: 第一个表面结构要求（参数代号+极限值+传输带/取样长度，如 0.0025-0.8/Rz6.3 或 -0.8/Rz6.3）
- **b**: 第二个要求（更多则符号竖向扩展）
- **c**: 加工方法/表面处理/涂层（车、磨、镀）
- **d**: 表面纹理方向符号
- **e**: 加工余量 (mm)
- 三种工艺符号: APA 允许任何工艺 / MRR 去除材料 / NMR 不去除材料
- 封闭轮廓各表面相同要求: 完整符号加一圈

### 8.5 常用件表示法索引 (GB/T 4459 系列)
- 螺纹及紧固件 (GB/T 4459.1): 牙底线细实线、终止线粗实线
- 齿轮/花键 (GB/T 4459.2/.3): 齿顶圆粗实线、分度圆点画线、齿根圆细实线(可省)
