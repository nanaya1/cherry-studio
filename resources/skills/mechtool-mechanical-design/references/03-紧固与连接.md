# 螺纹连接与紧固件速查

> 来源: mechtool.cn 连接件与紧固件栏目 (GB/T 192/193 螺纹、GB/T 5782 等紧固件标准)
> 标准件详细尺寸表见语料库: 检索 "GB/T 5782"、"弹性挡圈"、"双头螺柱" 等

## 1. 普通螺纹基础 (GB/T 192-2003 牙型 / GB/T 193-2003 直径螺距)

### 基本牙型几何关系
- 原始三角形高度 **H = 0.866025P**（P 为螺距）
- 螺纹各特征尺寸: 5/8H=0.5413P(牙高基准), 3/8H=0.3248P, 1/4H=0.2165P, 1/8H=0.1083P
- 常用计算: 螺纹大径 d ≈ 公称直径；中径 d₂ = d − 0.6495P；小径 d₁ = d − 1.0825P（≈d−1.08P）

### 直径与螺距标准组合 (粗牙/细牙)
| 公称直径D | 粗牙P | 常用细牙P | 公称直径 | 粗牙P | 常用细牙P |
|-----------|-------|----------|---------|-------|----------|
| M3 | 0.5 | 0.35 | M16 | 2 | 1.5, 1 |
| M4 | 0.7 | 0.5 | M18 | 2.5 | 2, 1.5 |
| M5 | 0.8 | 0.5 | M20 | 2.5 | 2, 1.5, 1 |
| M6 | 1 | 0.75 | M22 | 2.5 | 2, 1.5, 1 |
| M8 | 1.25 | 1, 0.75 | M24 | 3 | 2, 1.5, 1 |
| M10 | 1.5 | 1.25, 1, 0.75 | M27 | 3 | 2, 1.5, 1 |
| M12 | 1.75 | 1.25, 1 | M30 | 3.5 | 3, 2, 1.5, 1 |
| M14 | 2 | 1.5, 1 | M36 | 4 | 3, 2, 1.5 |
|  |  |  | M42 | 4.5 | 4, 3, 2, 1.5 |
|  |  |  | M48 | 5 | 4, 3, 2, 1.5 |
|  |  |  | M56 | 5.5 | 4, 3, 2, 1.5 |
|  |  |  | M64 | 6 | 4, 3, 2, 1.5 |

- 优先选用**第一系列直径** → 第二 → 第三；避免括号内螺距
- **细牙螺纹特点**: 小径大(强度高)、螺距小(自锁好、微调)、用于薄壁件/受振件/液压管接头；粗牙用于一般连接
- 螺纹代号: 粗牙 M20（不标螺距）；细牙 M20×1.5；左旋 M20-LH

### 螺纹公差 (GB/T 197)
- 公差带代号: 中径+顶径公差带，如 **6H**(内螺纹常用)、**6g**(外螺纹常用，镀前 6g/镀后 6h)
- 旋合长度: S(短)/N(中)/L(长)；精密件用 4H/4h，一般 6H/6g，粗装配 7H/8g

## 2. 螺栓性能等级与选用 (GB/T 3098.1)

### 性能等级标记含义
- 形式: **x.y**，如 8.8 → 抗拉强度 σb≈8×100=800MPa；屈强比 0.8 → σs≈640MPa
- 常见等级: 3.6 / 4.6 / 4.8 / 5.6 / 5.8 / 6.8 / 8.8 / 9.8 / 10.9 / 12.9
- **8.8级及以上 = 高强度螺栓**（合金钢淬火回火）；≤6.8 为低碳钢/中碳钢
- 螺母性能等级(数字=可配套螺栓最高等级): 4/5/6/8/10/12，如 8 级螺母配 8.8 级螺栓
- 应用: 一般机械 4.8/5.8 够用；重要连接/承受动载 8.8；汽车/钢结构 10.9

## 3. 预紧力控制方法

| 方法 | 精度 | 特点 |
|------|------|------|
| 感觉法 | ±40% | 靠经验，最经济；普通连接 |
| 力矩法(测力矩扳手) | ±25% | 广泛使用，成本低，表面润滑后精度提高 |
| 螺母转角法 | ±15% | 先拧到"密贴"再转角度 θ=p/(Cp...)；汽车/钢结构常用 |
| 螺栓伸长法 | ±3~5% | 弹性范围测伸长；特殊重要场合 |
| 应变计法 | ±1% | 贴应变片；费用昂贵 |
| 液压拉伸法 | 高 | 大螺栓(汽轮机等)预紧 |

感觉法拧紧力参考: M6≈45N(腕力) / M8≈70N(腕+肘) / M10≈130N(全手臂) / M12≈180N(上半身) / M16≈320N(全身) / M20≈500N(全身重量)

## 4. 防松方法

### 机械锁固型（可靠，用于重要/振动场合）
- 开口销+开槽螺母（航空/汽车/拖拉机，不适于双头螺柱）
- 穿金属丝（成组螺栓，注意钢丝走向防松方向）
- 止动垫圈（单耳GB854/双耳GB855/外舌GB856，需安装空间）

### 自由旋转型
- **弹簧垫圈**: 结构简单成本低，但弹力不均不十分可靠，多用于不甚重要连接；不宜用于表面不许划伤/常拆卸处。GB7245鞍形/GB7246波形改善
- **双螺母**: 先80%力矩拧下螺母(薄)，再100%拧上螺母(1型标准)；低速重载平稳载荷
- **扣紧螺母**: GB805 防松良好，不宜频繁装卸
- **弹性/齿形垫圈**: 内齿(钉头小)/外齿(力臂大止退力矩大)；锯齿型可高等级大规格；不适于被连件过软过硬
- **六角法兰面螺栓/螺母**: 加大支承面(dw≈2d)或带齿纹——"三合一"，适用于8.8级及以上重要连接(当代最新型式)

### 省略防松元件的条件
- 轴向载荷、8.8级以上、**夹紧长度 > 3d**：可不加防松（控制好预紧力仍有足够残余预紧力）
- 4.8/5.6/5.8级、夹紧长度 > 5d：同理
- 承受**径向载荷**或连接件弹性变形大的场合不适用省略

## 6. 螺纹连接设计要点
1. 受**横向载荷**(剪切)的普通螺栓靠预紧摩擦力工作，需较大预紧力；可铰制孔螺栓(GB/T 27)直接受剪更可靠
2. 预紧力过大会拉断螺栓或压溃被连接件；推荐预紧力 F₀≈(0.6~0.7)σs·A₁
3. 螺栓组设计: 结合面受力分析 → 求最不利螺栓载荷 → 定直径
4. 被连接件刚度大、螺栓刚度小 → 动载下螺栓应力幅小（用细长螺栓/弹性垫圈）
5. 拧紧力矩 T≈KF₀d，K≈0.2(无润滑)
6. 不锈钢/铝件用不锈钢螺栓防电化腐蚀；高温用合金钢；密封面加垫片
