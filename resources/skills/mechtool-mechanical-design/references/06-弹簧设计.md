**许用应力修正规则**:
- 重要弹簧(损坏影响大) → 许用应力适当降低
- 经**强压处理** → 可适当提高许用应力(抗松弛)
- 经**喷丸处理** → 许用应力可提高 20%
- 工作温度 >60℃ → 切变模量修正: **Gt = Kt·G** (Kt 温度修正系数)

## 4. 碟形弹簧 (GB/T 1972)

碟簧是由钢板冲压成形的**变刚度截锥形压缩弹簧**。

### 参数定义
- D—外径; d—内径; t—厚度; H₀—自由高度
- h₀—无支承面压平时变形量 = H₀ - t
- F—载荷(N); f—变形量(mm); b≈D/150—支承面宽度

### 按厚度分类 (GB/T 1972)
| 类别 | 碟簧厚度 t/mm | 支承面和减厚厚度 |
|------|-------------|-----------------|
| 1 | <1.25 | 无 |
| 2 | 1.25~6.0 | 无 |
| 3 | >6.0~14.0 | 有 |

### 系列 (D/t 与 h₀/t 比值)
- **系列A**: D/t≈18, h₀/t≈0.4, E=206GPa, μ=0.3
- **系列B**: D/t≈28, h₀/t≈0.75, E=206GPa, μ=0.3

## 6. 设计要点

1. 先定 **载荷类型(Ⅰ/Ⅱ/Ⅲ类)** → 决定安全系数与许用应力档位
2. 选材料: 一般机械用碳素弹簧钢丝/65Mn; 较高载荷用 60Si2MnA; 高温阀门用 50CrVA/55CrSi
3. 旋绕比 C 取 4~10 为宜(C过小加工难, 过大易失稳)
4. 压缩弹簧高径比 b=H₀/D > 2.6 时需考虑**稳定性**(加导杆/导套)
5. 温度 >60℃ 必须修正切变模量; 腐蚀环境选不锈钢/青铜; 导电防磁选铍青铜
6. 喷丸可提高许用应力 20%; 强压处理提高抗松弛能力
7. 碟簧可**组合使用**(叠合/对合), 叠合增加载荷, 对合增加变形量
