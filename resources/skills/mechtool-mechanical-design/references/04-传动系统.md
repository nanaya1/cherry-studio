# 传动系统速查（带/链/齿轮/蜗杆）

> 来源: mechtool.cn 传动栏目 (GB/T 13575.1 V带、GB 10085 蜗杆等)

## 1. 带传动

### 带的类型与选用
| 类型 | 结构/特点 | 适用 |
|------|----------|------|
| 平带 | 胶帆布(价廉耐湿)、编织带(曲挠好易松)、锦纶片复合(强度高摩擦大)、高速环形带(涤纶绳) | v<30m/s, P<500kW, i<6, 轴间距大 |
| **普通 V 带** | 楔角40°, 相对高度≈0.7, 当量摩擦因数大, 允许包角小、传动比大、预紧力小 | v<25~30m/s, P<700kW, i≤10, 轴间距小 |
| 窄 V 带 | 相对高度≈0.9, 能承受大预紧力、速度曲挠次数高、功率大、节能 | 大功率紧凑传动 |
| 联组 V 带 | 2~5 根粘结, 载荷均匀减少振动横转 | 要求高传动 |
| 齿形 V 带 | 内周齿形, 散热好曲挠性最好 | 同普通/窄V带 |
| 大楔角 V 带(60°) | 聚氨酯, 摩擦大功率大外廓小耐磨耐油 | 高速紧凑 |
| 宽 V 带 | 相对高度≈0.3, 曲挠耐热耐侧压 | 无级变速 |
| **多楔带** | 平带基体+纵向三角楔, 兼具平带柔软与V带摩擦力, 平稳外廓小 | 结构紧凑、V带根数多或垂直轴传动 |
| 同步带 | 梯形齿/圆弧齿(HTD), 啮合传动无滑动、传动比准确 | 精密同步传动 |

### V 带设计要点 (GB/T 13575.1)
- 截面型号: Y Z A B C D E（Y 最小）；普通V带按功率选型
- 带速: 一般 v=5~25 m/s（最佳 15~20），v<5 用低速挡增带轮
- 小带轮包角 α1≥120°（至少 90°）；传动比 i≤7(推荐≤5 单级)
- 根数: z = Pca/(P₁·Ka·KL)，Ka 包角系数、KL 长度系数
- 预紧力: F₀=500Pca(2.5/Ka−1)/(zv)+qv²
- 中心距与基准长度: 初定 a₀≈(0.7~2)(d₁+d₂) 后按 Ld 圆整
- 张紧: 定期张紧(移动电机)/自动张紧(摆架)/张紧轮(小带轮内侧松边)

### 同步带传动设计
- 梯形齿同步带(GB/T 11616 等)与圆弧齿同步带: 圆弧齿(HTD)承载能力与寿命优于梯形齿
- 选型: 设计功率 Pca=KA·P → 按节距 pb/模数 → 带宽 bs → 校核带速与啮合齿数
- 同步带轮: 齿形/节距与带匹配，最少啮合齿数≥6

### 多楔带设计 (JB/T 5983)
- 楔数按功率计算, 楔距 PH; 带轮楔角 40°, 主从动轮外径按基准直径

## 2. 齿轮传动

### 齿轮常用材料与热处理
| 材料工艺 | 硬度 | 特点与应用 |
|---------|------|-----------|
| 调质钢(45/40Cr) 调质或正火 | 220~300HBS | 强度韧性好、成本低、易跑合；中低速一般齿轮、大型齿轮 |
| 调质+高频感应淬火 | 合金钢45~55HRC, 碳钢40~50HRC | 齿面硬抗点蚀耐磨、齿根强度高(残余压应力)、需磨齿；承载高体积小 |
| 渗碳钢(20CrMnTi等) 渗碳淬火 | 56~62HRC | 齿面硬度最高、心部韧性好、耐冲击；变形大需磨齿；中小型高承载高精度 |
| 氮化钢 氮化 | 高(薄层) | 变形极小不需磨齿；承载不及渗碳；不宜冲击；大而平稳载荷、无磨齿设备时 |
| 铸钢 | — | 大型复杂形状齿轮, 强度低于锻钢 |
| 铸铁 | — | 价廉耐磨、工艺好、承载低；灰铁/可锻铁低速轻载, 球铁较大冲击 |

齿轮用钢选择参考: 不重要齿轮 45 调质；中速中载机床变速箱 40Cr/42SiMn/35SiMn 调质或调质+高频；汽车拖拉机/工程矿山机械低速重载大齿轮用渗碳钢(20CrMnTi)或表面淬火钢

### 齿轮结构形式
- 直径小(da<200mm): 齿轮轴(与轴一体)或实心齿轮
- 中径: 腹板式(辊板式)齿轮
- 大径: 轮辐式(铸造/焊接)
- da 与轴径接近(da<2d轴): 做成齿轮轴；轮毂长应≥齿宽

### 蜗杆传动
| 类型 | 特点 |
|------|------|
| 阿基米德蜗杆 ZA | 车制轴向直线齿廓, 加工方便应用广; 导程角大时加工难、磨损快; 低速小载 |
| 渐开线蜗杆 ZI | 可磨削精度易保证、效率高; 3头以上高速精密(滚齿机) **推荐** |
| 法向直廓蜗杆 ZN | 延伸渐开线, 单/双刀切制, 可磨齿; 机床多头精密副 |
| 锥面包络蜗杆 ZK | 锥面盘铣刀/砂轮包络, 刀具易制磨; 效率高 |
| 圆弧圆柱蜗杆 ZC | 凹面齿, 承载大效率高 |
| 直廓环面蜗杆 TSL | 承载为普通圆柱的4倍, 工艺复杂 |
| 平面包络环面蜗杆 TOP | 可淬硬磨削精度高效率高, 承载与TSL相当, 应用日广 |

- 蜗杆头数 z1: 1~6; γ<3°17' 可自锁(起重防逆转用, 效率低 0.4~0.45)
- 参数匹配: 中心距 a/模数 m/分度圆直径 d1/头数 z1/蜗轮齿数 z2/变位 x2 按 GB 10085 标准组合(如 a=40: m2 配 i9.5/19/38/49 等)
- 效率: ZA 0.5~0.8; ZI/ZN/ZK/ZC 可达 0.9; TSL 0.92; TOP 可达 0.97
- 蜗轮材料: 锡青铜(ZCuSn10P1 高速重要)、铝铁青铜(中速)、灰铸铁(低速大规格); 蜗杆 45/40Cr 淬硬磨削

## 3. 链传动（要点）
- 滚子链 GB/T 1243: 节距 p 越大承载越大; 链号 08A~48A(08A=节距12.7mm 等)
- 链轮齿数: 小链轮 z1≥17(优先≥19~21), 大链轮 z2≤120; 链速 v≤15m/s
- 特点: 无滑动平均传动比准确、效率高(0.95~0.98)、轴压力小、可在高温油污环境; 瞬时链速不均、有噪声

常见减速器类型与标准（选用要点）:
- **圆柱齿轮减速器** (JB/T 8853-2015): 展开式/分流式/同轴式；硬齿面(TH/TB 型)承载高
- **锥齿轮-圆柱齿轮**、**圆锥圆柱** 结构
- **行星齿轮 NGW 型** (JB/T 6502-1993): 结构紧凑、传动比大、同轴
- **摆线针轮减速器**: 传动比大(i=6~119)、结构紧凑、过载能力强、噪声低
- **蜗杆减速器** (见 04 主体部分)
- **釜用立式减速器**: 搅拌设备专用

电机选型要点（语料 motor 目录）:
- 常用电机特点用途表、电动机功率计算、启动/制动/运行特性、接触器与电气传动
- 功率选择: P_电机 ≥ P_工作机/η_总传动效率；变载按等效功率校核
