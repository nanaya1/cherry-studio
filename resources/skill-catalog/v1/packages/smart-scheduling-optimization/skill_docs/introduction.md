# 智能调度优化算法技能文档

## 技能概述

本技能基于NSGA-II多目标遗传算法，设计用于解决各类调度优化问题，特别是生产排产调度场景。当前在烟草设备排产的应用基础上，构建通用调度优化库，可适配厂-车间-机组等多层次调度需求。

## 技能适用范围

- 生产调度优化
- 资源分配问题
- 多目标约束优化
- 分层调度场景
- 复杂约束处理

## 标准化输出格式

- 优化方案列表：List<T> (Pareto前沿解集)
- 多目标值：double[m] (m个优化目标的数值)
- 约束满足度：double (约束违反惩罚值)
- 算法性能：时间复杂度O(M*N^2)，空间复杂度O(N^2)

## 使用原则

1. 明确问题的解空间结构和约束条件
2. 合理设定多目标权重以符合业务实际需要
3. 根据问题规模设定合理算法参数
4. 验证优化结果的可行性和合理性

## 扩展建议

- 针对特定行业需求扩展专用约束处理
- 通过并行计算提高大规模问题求解效率
- 与业务系统集成时注意接口协议和数据交换格式
