## What changed

The sidebar's Resource Center entry was removed from the main navigation and replaced by a "More" entry. Clicking "More" opens a secondary panel to the right that lists Resource Center, Translate, Paintings, and Knowledge.

## Why this matters to the user

The sidebar's main navigation is now three items (New task, Skills & Connectors, Scheduled Tasks). Users who opened Resource Center (or Translate / Paintings / Knowledge) directly from the sidebar must now go through the "More" panel. Existing routes and tabs are unchanged — only the entry points moved.

## What the user should do

Nothing — open these features from the "More" entry in the sidebar instead.
