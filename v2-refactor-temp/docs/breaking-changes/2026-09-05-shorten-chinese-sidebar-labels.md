## What changed

The Chinese UI labels were shortened: the conversations group is now `对话` (was `普通对话`) and the agent tasks group is now `任务` (was `智能体任务`). This covers the workspace sidebar group headers, the new-task page titles, the error diagnostic report location, agent-task delete dialogs, and system notifications about agent tasks.

## Why this matters to the user

Chinese-language users will see the shorter labels in the sidebar, the new-task chooser, dialogs, and notifications. Screenshots and UI references that mention the old wording will not match anymore.

## What the user should do

Nothing — automatic.
